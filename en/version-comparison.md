# Version Comparison

This file summarizes notable changes between versions of OpenNotes.

- AES-GCM 256 support for encrypting notes stored locally.
- PBKDF2 key derivation and SHA-256 hashing used for password-based encryption.
- UI: translated labels and improved settings flow.
- Notes storage: uses browser localStorage; no server required.

See the repository README for more details and usage instructions.
