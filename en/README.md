# OpenNotes - MarkDown Note App (English)

OpenNotes is a lightweight, client-side Markdown note application. It stores notes in the browser and supports optional encryption for storing sensitive notes. This repository contains a simple HTML single-file app and a settings page.

Features

- Markdown editor and preview
- Local storage of notes
- Optional note encryption (AES-GCM, PBKDF2, SHA-256)
- Simple settings page
- Plain static files — no backend required

Files translated into /en/

- README.md — this file
- index.html — main app UI (English)
- settings.html — settings UI (English)
- version-comparison.md — version comparison translated
- LICENSE — copied as-is

How to use

1. Open `index.html` in a browser.
2. Create, edit, and save notes locally.
3. Use the Settings page for encryption and other options.
