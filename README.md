# 📒贪吃的笔记 - 开源的备忘录与笔记工具【Pre-release】
在线体验：https://tanchipanda.github.io/TanchiNotes/index.html

## 🕯️功能亮点
1️⃣支持 MarkDown 代码，提供双栏、写作视图和阅读视图三种模式

2️⃣自带加密笔记本，并使用 **AES-GCM** 256 位加密，密钥通过 PBKDF2（10 万次迭代 + SHA-256） 从密码派生，**保存在本地设备中，所有数据不通过云端**

3️⃣支持管理页面标签，使用标签整理数据

4️⃣提供丰富的格式，助你高效地编辑文件、记录笔记
